# Fictional memory examples

These examples are documentation only. The installer does not seed them.

| Destination | Example |
| --- | --- |
| `memories/USER.md` | The exhibit coordinator prefers a short checklist followed by caveats. |
| `memories/MEMORY.md` | Exhibit approvals are recorded in `Decisions/` of the selected sample vault. |
| Daily log | The fictional library team held a lighting review and saved a decision note. |
| Project evidence | The exact approval text and its source belong in the vault decision note. |
| `skills/` | The recurring evidence lookup procedure belongs in the bundled `vault-evidence` skill. |

Do not promote an isolated past event into a permanent preference. When a decision changes, keep the historical note and reference the current decision separately.
